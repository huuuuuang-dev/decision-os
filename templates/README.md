# 可复用模板

## 概念卡

- 概念与一句话定义
- 它解决的问题
- 核心机制和证据来源
- 可用场景、局限、反例
- 相关页面和可执行动作
- 最新修订及依据

## 项目卡

- 一句话定义、用户与痛点
- 核心交付、渠道和付费场景
- 关键资源、最大风险和损失上限
- 已验证事实、当前判断和未验证假设
- 未来七天可完成的最小验证
- 相关协议、复盘日期和更新记录

## 判断协议

- 判断目标、适用范围和所需输入
- 步骤、评分维度、红线和退出条件
- 输出格式、示例和适用边界
- 相关证据、版本和修订依据

## 验证记录

- 日期、问题及原先判断
- 假设、可能反例和改变判断的条件
- 最小测试、可承受损失和观察指标
- 实际结果及证据来源
- 修订后的判断、下一步和应更新页面
