# Decision OS

Decision OS 是一套个人认知与决策框架。它把世界观、成长策略、项目判断和行动反馈连起来，帮助使用者记录自己为何作出判断，以及哪些证据会改变判断。

**工作循环** · 明确先验与约束 → 比较选项 → 选择可承受的行动 → 观察反馈 → 更新判断与知识库。

## 用一次决策跑通循环

选一个近期项目。写下目标、选项、举棋不定的原因和损失上限。找一个可比案例，记录哪条新证据会改变行动。选一个小规模、可逆的验证动作，约定复盘时间。复盘时把新证据、判断变化和下一步写回知识库。
