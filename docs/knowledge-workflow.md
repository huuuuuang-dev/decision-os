# 知识库与 Agent 工作流

1. **原始输入**。从阅读、讨论、项目记录和现实反馈中提取可复用信息，记下来源与时间。
2. **Obsidian 主库**。按单一主题维护 Markdown 页面，链接概念、项目、协议和证据。主库保存重要判断的修订记录。
3. **LLM Wiki 编译层**。把原始输入整理成可检索的摘要、概念卡和方法卡，保留回到证据的路径。
4. **Agent 调用层**。分析前查询相关概念、项目和协议。输出已有共识、当前判断、假设、反例、缺失证据和下一步。发现与新事实冲突时，标出冲突和相关页面。
5. **写回**。只摘录有持续价值的新判断、假设、证据和行动。记录日期、来源与应更新的页面。反复发生且输入输出稳定的流程可沉淀为 Skill。

## 最小闭环

收集一份资料 → 写一张知识卡 → 用于一次项目判断 → 执行一个验证动作 → 根据反馈更新项目页和判断协议。
