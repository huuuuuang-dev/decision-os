## 行动如何更新模型

叙事影响可见的机会，自我模型影响能动性，资源与安全边界决定试错规模。场域诊断、位置资本与合作网络帮助决定继续深耕还是移动。短周期行动给出反馈，反馈用于更新对场域、个人能力与可选行动的认识。

## 应用场景

- **家庭与教育决策**。明确参与者的目标与约束，记录可能改变选择的证据，提供适合自主判断的信息。
- **本地服务与文旅**。以痛点、支付场景、交付标准和可信入口作为初步验证对象。
- **AI-ready 商品层**。把服务的适用对象、权益、限制、交付流程及证据整理成 Agent 可查询、可比较的字段，并明确交付和责任归属。

这些场景是可应用框架的方向。用[验证记录](../templates/README.md#验证记录)记录假设、实验和结果。
