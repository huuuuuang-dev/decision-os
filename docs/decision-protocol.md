# 决策与复盘协议

适用于存在多种行动、信息不完整且投入有代价的判断。项目机会、学习策略和工具选型可以复用同一结构。

1. **定义决策**。写明目标、决策人、时间窗口、当前选项和维持现状的后果。
2. **找参考类**。用可比案例建立基准，同时记录样本来源、差异和选择偏差。
3. **估计结果分布**。写出较好、常见和较坏的情景，标出尾部损失及恢复条件。用概率范围表达证据质量允许的精度。
4. **检验信息价值**。优先寻找会改变选择、行动时机或投入规模的信息，提前写下改变判断的阈值。
5. **确定行动边界**。检查可逆性、可承受损失和退出条件。考虑行动能否改善下一轮选项。
6. **做最小验证**。选择一个可执行的实验，写下需要观察的信号、时间和复盘日期。
7. **更新记录**。区分已有观察、当前判断与待验证假设，记录反例和下一步。用决策时可获得的信息评价过程。

## 示例

评估一个本地路线服务时，先用一条路线测试需求。预先定义何种询价、预约及交付反馈足以推动第二轮。记录同类服务的有偿转化、每次交付的投入和可能的退出成本。试验结束后，复盘需求、渠道和交付各自有哪些证据。

示例为说明协议用途而拟写。
