# 底层信念与先验

先验是进入判断、学习、合作和行动之前带入的默认假设。它影响事实如何被解释、错误如何被处理、哪些行动值得尝试。筛选先验时，考察它是否尊重证据、支持行动、保留边界并扩大未来选择。

| 层级 | 适用场景 | 代表先验 |
| --- | --- | --- |
| S · 人格与生存 | 试错、风险约束、自主性 | 错误提供反馈。事实优先。资源有限，选择有后果。生存先于胜利。 |
| A · 成长与学习 | 训练、学习和合作 | 练习和反馈推动能力增长。注意力需要保护。好奇心支持长期学习。行动能产生新信息。 |
| B · 复杂系统与决策 | 预测、创业、项目和风险 | 记录参考类和尾部风险。用新证据更新概率。先界定可承受损失，从小样本开始。复盘同时检查决策过程和结果。 |
| C · 关系与长期生活 | 家庭、合作、意义与生活质量 | 可靠关系支持探索。善意需要边界。持续合作依赖信任和可兑现的承诺。 |

## 复盘先验

1. 写下这次判断中实际采用的默认假设。
2. 回看它带来了哪些行动和反馈，改变了哪些未来选项。
3. 记录可以检验它的反例，说明哪些场景需要换一个假设。
4. 给修订加上日期、理由、证据及影响的页面。

配合[决策与复盘协议](decision-protocol.md)使用。
